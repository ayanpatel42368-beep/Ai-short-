# 🎬 ShortForge AI
Convert YouTube videos into viral TikTok/Reels shorts using AI.

## Quick Start
1. Install Node.js from https://nodejs.org/
2. Run: `npm install`
3. Run: `npm start` (for dev) or `npm run build-apk` (for APK)

## Features
- AI viral moment detection
- Auto transcription (Whisper)
- 9:16 vertical format
- Auto captions
